# Phase 20 — threats to validity and publication boundaries

**Construct:** Git revision is not deployment, RPKI day is not operation time,
RIS source time is not replay arrival, DNS file coverage is not entity/answer
knowledge. Different native units cannot be ranked or pooled as changes/s.

**Internal:** parser/canonicalization work, JVM/startup, Kafka batching, Parquet
layout, metadata/indexing, oracle validation, service contention and cache warmth
differ. New E2R queries include disk materialization and independent comparison.
Startup/import and physical query I/O are unmeasured. Fresh process/build is not
cold filesystem cache; no privileged eviction. Earlier service results do not
form matched B0/B2/B3 engine comparisons. The canonical tuple evaluation layout
differs from original production multi-column Parquet; do not rank those unmatched
byte counts. The new pilot proves rewrite exactness only, not service feasibility.

**External:** one Apple M3 Pro, one trust anchor, one collector/hour, two selected
OpenINTEL objects, filtered sparse public Git history. No multiworker cluster,
horizontal scaling, enterprise deployment or universal BGP validity evidence.

**Statistical:** three independent builds/configuration with three warm cycles
are descriptive. Report every value, median/range and paired ratios; do not infer
population confidence or significance. Keep failed bootstrap, prior OOM and
interruption distinct. Later successful retained finalization does not erase
failure or retroactively make the ingestion a clean successful benchmark.

**Reproducibility:** pinned private third-party sources/normalized oracles, exact
public hashes, owned CI fixtures, library/service versions and resource guards.
Shared PyArrow codec qualifies Parquet oracle independence; RIS required projection
Level3 retains pinned-parser disposition limits. Original source retention is
required for nonprojected fields. Read-only object listing is not a new identity
or physical-file checksum audit.

**Rights:** no raw archives, DNS names, normalized external rows, checkpoints,
Kafka payload logs or credentials published. Preserve [OpenINTEL attribution](phase19-source-attribution.md)
and [terms](https://openintel.nl/download/terms/) (CC BY-NC-SA 4.0, attribution,
redistribution conditions; rechecked). RIPE copyright fetch timed out in this
assessment; do not invent unrestricted redistribution permission. Prior attributed
private research scope retained; Terraform filtering/root-license evidence is not
every historical source-file adjudication. Instructor approval NOT_VERIFIED.

**Approval:** bounded local work is authorized; full repeated service matrix and
long paced RIS execution require a specific new budget/owner decision. Neither
expired earlier budgets nor this evaluation prompt implies unlimited execution.
Public paper approval and Phase21 are separate gates.
